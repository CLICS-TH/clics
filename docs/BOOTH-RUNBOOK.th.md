# คู่มือประจำบูท CLICS · NFCME-2026

**1. เปิดเครื่อง** หน้าบูทคือ `physician-ui.vercel.app/booth` เปิดจอก่อน แล้วเปิดมินิพีซี Chrome จะเปิดหน้านี้เต็มจอเอง ถ้าไม่ขึ้นหรือถามกู้คืนแท็บ ให้กด Alt+F4 แล้วดับเบิลคลิก `booth-kiosk.cmd` บนเดสก์ท็อป

**2. ระบบสัมผัส** แตะมุมจอ จุดที่ตอบสนองต้องตรงนิ้ว ถ้าไม่ตรง: Settings > Display > Orientation ให้ตรงกับที่จอตั้งอยู่ (จอตั้ง = Portrait, จอนอน = Landscape ห้ามหมุนจอนอนเป็น Portrait) แล้ว Control Panel > Tablet PC Settings > Setup แล้วแตะจอตามที่บอก

**3. อินเทอร์เน็ต** ใช้ Wi-Fi ของงานเป็นหลัก เปิดฮอตสปอตโทรศัพท์สำรองไว้ตลอด (ตั้ง Connect automatically ทั้งคู่) ถ้าเครื่องไม่ต่อฮอตสปอตเอง ให้เลือกที่ไอคอน Wi-Fi มุมขวาล่าง

**4. แถบล่างจอ** (เปลี่ยนเองภายใน 30 วินาที)

| แถบแสดงว่า | ความหมาย | ทำอะไร |
|---|---|---|
| แตะเพื่อเริ่ม (มีวงกลมกะพริบ) | พร้อมเล่น | ไม่ต้องทำ |
| ขณะนี้เชื่อมต่อ CLICS ไม่ได้ | เน็ตหลุด วิดีโอยังเล่นได้ | ทำตามข้อ 3 |
| ขณะนี้บูทปิดอยู่ | สวิตช์ปิด หรือนอกเวลาเปิด | โทรตามข้อ 7 |

ถ้าแถบ "เชื่อมต่อ CLICS ไม่ได้" ยังอยู่เกิน 5 นาที โทรตามข้อ 7 · ผู้เล่นทิ้งเครื่องกลางทาง จอจะถาม "ยังอยู่ไหม" แล้วกลับหน้าแรกเอง

**5. เปิดปิดงาน (superadmin)** ล็อกอินที่ `physician-ui.vercel.app/login` ไปที่หน้าโหมดบูธ (`/admin/booth` เมนู ระบบ → โหมดบูธ) การ์ดการตั้งค่างาน ตั้งเวลาเปิดและปิด (เวลาไทย) แล้วกดปุ่ม **บันทึก / Save** (เวลาที่พิมพ์แต่ไม่กดบันทึกจะไม่มีผล) จากนั้นแตะสวิตช์ **เปิด** ทุกเช้า และ **ปิด** ทุกเย็นเมื่อปิดบูท สวิตช์บันทึกเองทันทีที่แตะ (ถ้าเปิดค้างข้ามคืน ใครก็เล่นและใช้ค่า AI ได้)

**6. ออกจากโหมดเต็มจอ** ต่อคีย์บอร์ด USB กด Alt+F4 แล้ว Shut down ตามปกติ เปิดกลับด้วย `booth-kiosk.cmd`

**7. ติดต่อ** (เขียนด้วยมือหลังพิมพ์ ห้ามใส่ในไฟล์นี้)

| เรื่อง | ชื่อ | โทร |
|---|---|---|
| เครื่อง จอ เน็ต | | |
| CLICS / เปิดปิดงาน | | |

**8. หลังวันสุดท้ายของงาน** ผู้ดูแลระบบแตะสวิตช์ **ปิด** ข้อมูลการเล่นทั้งหมดเก็บไว้ ไม่ต้องลบ สคริปต์ `purge-event.mjs` ใช้เฉพาะกับงานทดสอบ หรือเมื่อเจ้าของโครงการสั่งให้ลบเท่านั้น

**9. เคสแบบ 5 ข้อ** ผู้เล่นตอบเคสละ 5 ข้อ กระดานคะแนนจัดอันดับเฉพาะการเล่นแบบ 5 ข้อ การเล่นแบบ 3 ข้อของรอบก่อนยังเก็บไว้ครบแต่ไม่ขึ้นกระดานแล้ว ระบบแบบ 5 ข้อจะเริ่มใช้จริงเมื่อเจ้าของโครงการอนุมัติ และทุกเคสที่จะให้เล่นมีตารางคะแนนแล้ว พร้อมผลแซนด์บ็อกซ์ที่ผ่าน หรือการยกเว้นจากเจ้าของโครงการที่ทำกับเคสแบบ 5 ข้อชุดนี้เอง เคสที่ยังไม่ครบจะไม่ถูกสุ่มมาให้เล่น ถ้าไม่มีเคสไหนครบเลย บูทจะไม่มีเคสให้เล่นและแถบล่างจอขึ้นว่าบูทปิดอยู่ ให้โทรตามข้อ 7

**10. แบบประเมิน** หลังเล่นจบ ผู้เล่นตอบแบบประเมินสั้น ๆ ได้ที่มือถือของตัวเอง ไม่ระบุตัวตน

- **สวิตช์:** ปุ่ม "ให้ความเห็น" ข้างปุ่ม "เสร็จแล้ว" บนหน้าคะแนน จะขึ้นก็ต่อเมื่อตั้ง `window.CLICS_BOOTH_FEEDBACK = true` ใน `physician-ui/public/js/config.js` (เปิดแล้วตั้งแต่ 25 พ.ย. 2569 ก่อนย้ายไป vm1 ค่าที่ใช้จริงคือไฟล์ `config.js` ในชุดที่ดีพลอยขึ้น Vercel ทุกครั้งที่ดีพลอย Portal ต้องใส่บรรทัดนี้ด้วย) แตะปุ่มแล้วจอขึ้น QR ไปที่ `/booth-feedback.html` และหน้าผลบนมือถือจะมีการ์ดแบบประเมินด้วย ค่านี้เปลี่ยนได้ด้วยการแก้ไฟล์แล้วดีพลอย Portal ใหม่เท่านั้น ไม่มีสวิตช์ในหน้าแอดมิน
- **ลำดับเปิดใช้ (เจ้าของโครงการทำ):**
  1. เจ้าของโครงการรัน `db/migration-booth-feedback.sql` ก่อน
  2. ดีพลอยแบ็กเอนด์
  3. ดีพลอยแดชบอร์ด
  4. ดีพลอย Portal โดยยังตั้ง `CLICS_BOOTH_FEEDBACK` เป็น `false`
  5. ทดสอบโดยไม่เสียค่า AI: ส่งคำตอบทดลอง 1 ชุดผ่านฟอร์ม ถ้าทดสอบกับแบ็กเอนด์ที่ไม่ใช่ของจริง ลบแถวนั้นได้ตามสะดวก แต่ถ้าทดสอบกับของจริง ระบบเก็บคำตอบได้เฉพาะตอนที่งาน NFCME-2026 เปิดอยู่ เพราะงานที่ไม่มีโฟลเดอร์เคสของตัวเองจะเปิดบนของจริงไม่ได้ ให้ปล่อยแถวทดลองไว้ ซึ่งดูออกจากวันที่ หรือให้เจ้าของโครงการลบแถวนั้นแถวเดียวด้วย SQL โดยระบุรหัสงาน วันที่ส่ง และรหัสเคสให้ตรง ห้ามใช้ `purge-event.mjs` ลบคำตอบทดลอง เพราะสคริปต์นี้ลบการเล่นทุกแถวของงานนั้นก่อน (ข้อ 8)
  6. ตั้ง `CLICS_BOOTH_FEEDBACK` เป็น `true` แล้วดีพลอย Portal อีกครั้ง
- **รับคำตอบเฉพาะตอนบูทเปิด:** ถ้าบูทปิดแล้ว ระบบตอบว่าปิดและไม่เก็บอะไรเลย ผู้เล่นที่ตอบหลังเวลาปิดจึงเสียคำตอบนั้นไป
- **อ่านคำตอบ:** superadmin ที่หน้าโหมดบูธ (`/audit/admin/booth`) ส่วน "ความเห็นผู้เล่น (Player feedback)" ดูจำนวนตามวัน แยกเคส และดูความเห็นได้ ปุ่ม "Export แบบประเมิน (JSON)" จะดาวน์โหลดไฟล์ผ่าน `GET /admin/booth/feedback.json` และบันทึกรายการตรวจสอบ `booth.feedback_export` ทุกครั้ง ความเห็นที่ระบบคัดว่าต้องให้ผู้ตรวจดู (`flaggedForAuditor`) จะขึ้นว่า "ถูกซ่อน" ไม่แสดงข้อความ ถ้ายังไม่ได้ตั้งรหัสงานของบูท หน้านี้จะขึ้น "ยังไม่มีแบบประเมิน" และไม่มีปุ่มส่งออก
- **ความไม่ระบุตัวตน** (ADR 0015): แต่ละแถวเก็บแค่วันที่ส่ง (ไม่มีเวลา) และเคส ไม่มีแท็ก ไม่มีรหัสการเล่น ไม่มีคะแนน และไม่มีข้อมูลไอพีหรืออุปกรณ์ การอ่านและการส่งออกเรียงแถวตามเนื้อหา ไม่ใช่ตามลำดับที่บันทึก ความเห็นที่พิมพ์จะผ่านการลบข้อมูลระบุตัวตนที่ rimpl ก่อนเก็บ ถ้าขั้นนั้นไม่สำเร็จจะไม่เก็บอะไร ข้อจำกัด: ล็อกการเข้าถึงของเซิร์ฟเวอร์ และลำดับแถวในฐานข้อมูลสำหรับคนที่เข้าถึง SQL ตรง ๆ อยู่นอกขอบเขตนี้ และในวันซ้อมที่มีคนเล่นน้อย เคสบวกวันที่อาจแคบลงเหลือไม่กี่การเล่น
- **ลบข้อมูลของงาน:** `scripts/booth/purge-event.mjs` ลบแถวแบบประเมินของงานนั้นด้วย โดยลบหลังลบการเล่นเสร็จ และลบได้ทั้งงานเท่านั้น ลบเฉพาะแบบประเมินอย่างเดียวไม่ได้ รันแบบไม่ใส่ `--delete` จะแค่แสดง "feedback rows: N" ไม่ลบอะไร ให้รันเฉพาะเมื่อเจ้าของโครงการสั่งเท่านั้น (ตามข้อ 8) ผู้ดูแลหน้างานห้ามรันเอง
