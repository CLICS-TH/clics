# คู่มือประจำบูท CLICS · NFCME-2026

**1. เปิดเครื่อง** เปิดจอก่อน แล้วเปิดมินิพีซี Chrome จะเปิดหน้าบูทเต็มจอเอง ถ้าไม่ขึ้นหรือถามกู้คืนแท็บ ให้กด Alt+F4 แล้วดับเบิลคลิก `booth-kiosk.cmd` บนเดสก์ท็อป

**2. ระบบสัมผัส** แตะมุมจอ จุดที่ตอบสนองต้องตรงนิ้ว ถ้าไม่ตรง: Settings > Display > Orientation = Portrait แล้ว Control Panel > Tablet PC Settings > Setup

**3. อินเทอร์เน็ต** ใช้ Wi-Fi ของงานเป็นหลัก เปิดฮอตสปอตโทรศัพท์สำรองไว้ตลอด (ตั้ง Connect automatically ทั้งคู่) ถ้าเครื่องไม่ต่อฮอตสปอตเอง ให้เลือกที่ไอคอน Wi-Fi มุมขวาล่าง

**4. แถบล่างจอ** (เปลี่ยนเองภายใน 30 วินาที)

| แถบแสดงว่า | ความหมาย | ทำอะไร |
|---|---|---|
| แตะเพื่อลอง CLICS | พร้อมเล่น | ไม่ต้องทำ |
| ขณะนี้เชื่อมต่อ CLICS ไม่ได้ | เน็ตหลุด วิดีโอยังเล่นได้ | ดูข้อ 3 นานกว่า 5 นาทีโทรข้อ 7 |
| ขณะนี้บูทปิดอยู่ | สวิตช์ปิด หรือนอกเวลาเปิด | โทรผู้ดูแลระบบ |

ผู้เล่นทิ้งเครื่องกลางทาง จอจะถาม "ยังอยู่ไหม" แล้วกลับหน้าแรกเอง

**5. เปิดปิดงาน (superadmin)** ล็อกอินที่ `physician-ui.vercel.app/login` ไปที่ Overview การ์ด Booth Mode ตั้งเวลาเปิดและปิด (เวลาไทย) แล้วกดปุ่ม **บันทึก / Save** (เวลาที่พิมพ์แต่ไม่กดบันทึกจะไม่มีผล) จากนั้นแตะสวิตช์ **เปิด** ทุกเช้า และ **ปิด** ทุกเย็นเมื่อปิดบูท สวิตช์บันทึกเองทันทีที่แตะ (ถ้าเปิดค้างข้ามคืน ใครก็เล่นและใช้ค่า AI ได้)

**6. ออกจากโหมดเต็มจอ** ต่อคีย์บอร์ด USB กด Alt+F4 แล้ว Shut down ตามปกติ เปิดกลับด้วย `booth-kiosk.cmd`

**7. ติดต่อ** (เขียนด้วยมือหลังพิมพ์ ห้ามใส่ในไฟล์นี้)

| เรื่อง | ชื่อ | โทร |
|---|---|---|
| เครื่อง จอ เน็ต | | |
| CLICS / เปิดปิดงาน | | |

**8. ลบข้อมูล** 30 วันหลังวันสุดท้ายของงาน ผู้ดูแลระบบแตะสวิตช์ปิด แล้วใน `backend/` รัน `node ../scripts/booth/purge-event.mjs --event NFCME-2026` เพื่อดูสรุป

- รันคำสั่งเดิมต่อท้าย `--delete` เพื่อลบ แล้วส่งบล็อกแรกที่พิมพ์ให้ CCME
- ถ้าการลบล้มเหลว ห้ามรัน `--delete` ซ้ำ ให้รันคำสั่งที่หน้าจอบอก แล้วส่งบล็อก already purged at … (บล็อก previous purge at … คือการลบครั้งก่อน)
