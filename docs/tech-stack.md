# Tech Stack

- **Physician UI:** static HTML/JS (no build step), single `public/css/main.css` (CSS custom-property design tokens), Chart.js via CDN, `@supabase/supabase-js@2.49.4` from esm.sh (version-pinned), and Google's sign-in script `https://accounts.google.com/gsi/client` (ADR 0008), loaded only after a visitor presses "Continue with Google". The Google script carries no SRI hash on purpose: Google serves it unversioned and changes it without notice, so a hash would break sign-in the day Google updates it. Do not "fix" that. Fonts are self-hosted. Dark/light + desktop/mobile toggles via `public/js/boot.js`; shared bilingual labels + the `cssVar` helper in `public/js/labels.js`; shared line-icons (`public/js/icons.js`, `icon(name,size)`) and toast/confirm dialogs (`public/js/ui.js`). Served on Vercel (`vercel.json`: `outputDirectory: public`, `cleanUrls: true`). Note: the per-page `<head>` (the no-FOUC boot snippet + font links) is intentionally duplicated across the 6 HTML files — without a build step there's no way to share it, and the boot snippet must be inline to run before first paint.
- **Audit Dashboard:** Next.js **16.2.7** (App Router), React **19.2.4**, Tailwind **v4** (`@theme` block, config-less), shadcn-on-Base-UI, recharts, **react-markdown `^9.1.0` + remark-gfm `^4.0.1`** (auditor transcript). Custom `ThemeProvider` / `ViewportProvider` (no `next-themes`). Shared design-system pieces (added in the 2026-06 design audit): `components/{BiLabel,Overlays,Markdown,DomainScorer}.tsx`, `lib/chart-colors.ts` (hex constants for recharts) + `lib/pis7-rubric.ts` (rubric anchors, mirrors `rimpl/src/lib/prompts.js`); semantic chart tokens `--chart-pass/-fail/-threshold/-warn` and `--coral-active` in `app/globals.css`. ⚠️ This Next is newer than most training data — read `audit-dashboard/node_modules/next/dist/docs/` before touching Next APIs (see `audit-dashboard/AGENTS.md`).
- **Backend:** Node.js + Express (port 3001), Supabase SDK (auth + DB), Anthropic SDK (via RIMPL). JWT auth via Supabase Auth (`signInWithPassword` / `auth.getUser`).
- **Database:** Supabase / PostgreSQL, AES-256 at rest, row-level security.
- **Middleware:** RIMPL (custom, on-premise, port 3003), Claude-only today (see [architecture.md](architecture.md) / [MIDDLEWARE-KNOWN-GAPS.md](MIDDLEWARE-KNOWN-GAPS.md)).
- **AI Providers (planned):** Claude (Anthropic), GPT-4o (OpenAI), Gemini (Google Vertex AI), Mistral — randomized per session via L4. **Currently only Claude (`claude-sonnet-4-6`) is wired.**

## Design system

Anthropic warm-editorial: cream canvas `#faf9f5`, coral `#cc785c` (active `#a9583e`), dark navy `#181715`, ink `#141413`. Display = Cormorant Garamond + Noto Serif Thai; body = Inter + Noto Sans Thai; mono = JetBrains Mono. Bilingual (Thai/English) throughout. Full spec: `DESIGN-claude.md`.

The two apps get those fonts differently:

- The **audit-dashboard** self-hosts them. The woff2 files are committed under `audit-dashboard/app/fonts/` and loaded with `next/font/local`, so `next build` needs no network. Provenance, sha256 and licences are in `audit-dashboard/app/fonts/README.md`.
- The **physician-ui** self-hosts the same five files under `physician-ui/public/fonts/`, declared once in `public/css/fonts.css` and linked from every page `<head>`, so no page contacts `fonts.googleapis.com` or `fonts.gstatic.com`. The responsive smoke fails if any file under `physician-ui/public/` names either host, or if a page it loads requests one. See `physician-ui/public/fonts/README.md`.
